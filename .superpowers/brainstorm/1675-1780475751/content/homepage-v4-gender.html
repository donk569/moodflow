动物表情说明

目前 mockup 用了系统 emoji 近似表达。实际 App 需要一套自定义小狗/小猫插画，每种情绪有对应的可爱表情：

🐾 小狗情绪包（9 种）

开心摇尾巴 / 焦虑耷耳朵 / 难过趴着 / 疲惫打哈欠 / 烦躁皱眉 / 空虚发呆 / 平静闭眼 / 无聊玩骨头 / 兴奋扑跳

😺 小猫情绪包（9 种）

开心眯眼 / 焦虑炸毛 / 难过垂尾 / 疲惫瘫倒 / 烦躁甩尾 / 空虚望窗外 / 平静呼噜 / 无聊玩毛线 / 兴奋竖尾

A

用现成 sticker 包

Flutter 有 sticker 相关包，找一套现成小狗小猫表情 sticker 集成

B

设计师画 SVG/Lottie

定制 18 个（9狗+9猫）矢量插画，微动画，品质最高但成本也高

C

AI 生成 + 人工修图

用 Midjourney/DALL·E 生成小狗小猫表情包，设计师调色统一风格
